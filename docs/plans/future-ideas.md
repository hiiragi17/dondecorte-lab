# 今後できれば（アイデアメモ）

PWA 化プランの議論から派生した、優先度未定の機能アイデア。
着手する時に改めて issue 化する。

## X (Twitter) 投稿ウォッチャー

- ドンデコルテ公式 / メンバー個人アカウントの新規投稿を定期取得
- 新着があれば Web Push で通知 + `topics` テーブルに自動流し込み
- 取得手段の候補:
  - X API（有料・基本プランで月 100 ツイート読み取り。コスト要確認）
  - Nitter インスタンス経由の RSS（不安定。インスタンス選定が必要）
  - 公式 RSS は提供なし
  - ※着手前に ToS / robots.txt / 利用許諾（商用利用・保存・再配信可否・レート制限）を確認し、不可なら手動運用へ切替
- 重複判定キー: ツイート ID（`topics.external_id` を追加）
- `topics.source` に `'x'` を追加、`url` にツイート URL
- 取得頻度: 15〜30 分粒度の Vercel Cron

## YouTube 新着即時通知

- issue #38（YouTube 動画自動取得）の Cron 結果を Web Push に流すだけ
- 低コストで効果が大きい — PWA / Push 基盤ができれば即座に乗せられる
- 新規追加された `videos` レコードを検出して通知（`is_notified` 相当のフラグを `videos` にも追加 or `notifications_sent` テーブルで管理）
- 通知本文: 動画タイトル + サムネ、タップで動画詳細ページへ

## M-1 / R-1 シーズン特設モード

- 大会期間中（10〜12 月 / 2〜3 月）だけトップを切り替え
- 表示内容:
  - 準々決勝〜決勝の日程・会場・配信リンク
  - 結果速報（敗退 / 通過 / 順位）
  - 過去成績との並び表示（`achievements` を活用）
- 実装案:
  - `seasonal_features` テーブル（start_at / end_at / kind / payload jsonb）で管理
  - トップページが期間内ならバナーセクションを差し込み
- 通知連動: 「準々決勝 X 日目に出場」「決勝進出」などをタイミング通知

## 誕生日カウントダウン

- 渡辺銀次さん / 小橋共作さん の誕生日、コンビ結成日
- `artists` / `comedy_groups` に `birthday date` / `formed_on date` カラムを追加
- 表示場所:
  - 各芸人 / コンビ詳細ページにバッジ
  - トップに「次のメモリアルまで X 日」ウィジェット（直近 30 日以内のみ）
- 当日通知（Web Push）も任意でオン
